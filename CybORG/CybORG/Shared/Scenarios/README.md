## CAGE 2 Scenario Generation

Use the script `scenario_generation.py` to generate new scenario files for experiments. Parameters are as follows:

- `Subnets`: Number of subnets
- `Operational_N`: Number of operational hosts
- `Enterprise_N`: Number of enterprise hosts
- `Resilience_N`: Number of each resilience-tied host to generate
- `User_N`: Number of user hosts
- `Operational_w`: Reward weight of operational hosts. 
- `Enterprise_w`: Reward weight of enterprise hosts
- `User_w`: Reward weight of user hosts
- `Operational_s`: Subnet #s of operational hosts
- `Enterprise_s`: Subnet #s of enterprise hosts
- `User_s`: Subnet #s of user hosts
- `Resilience_s`: Subnet #s of resilience-tied hosts
- `Defender_s`: Defender agent start subnet
