# CyberResilience attribution

The Python modules in this directory are adapted from
[CyberResilience](https://github.com/xcadet/CyberResilience), the implementation of
Cadet et al.'s **Quantitative Resilience Modeling for Autonomous Cyber Defense**.
The corresponding upstream files have the same filenames at the repository root;
`__init__.py` provides local package initialization.
